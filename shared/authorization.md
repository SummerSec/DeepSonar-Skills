# 授权与使用边界

本仓库 skill 仅用于：

1. **已获书面授权** 的安全评估 / 红队 / 漏洞众测范围  
2. **自有系统** 或雇主明确授权资产  
3. DeepFlowHunter 等平台中对 **用户提交、已授权** 的目标执行审计  

## 禁止

- 未授权扫描、爆破、利用第三方生产系统  
- 编写/传播可直接武器化的完整 exploit 包（报告中只保留验证所需最小步骤）  
- 对真实用户数据做破坏性验证（删库、勒索、持久化后门）  
- 将目标凭据、生产密钥写入公开渠道  

## 黑盒默认纪律

- 先确认 **scope**（域名、IP、账号、时间窗）  
- 破坏性 payload 仅在隔离/预发/明确允许时使用  
- 默认限速；避免 DoS  
- 发现 Critical 后优先 **报告与止血建议**，不横向扩大未授权范围
