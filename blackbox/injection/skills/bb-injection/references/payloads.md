# Injection 最小验证提示

> 仅用于已授权验证。不要构建完整攻击框架。

## 探测方向

- 登录/搜索/过滤/排序/导出接口的参数污染
- 命令类功能: ping/诊断/导出/转换
- JSON body 注入 Mongo 操作符

## 合格证据

- 可读全库/写库/读文件/执行系统命令
- 盲注可稳定抽取敏感数据或拿 shell
- 多租户下可跨租户读数据

## 不合格（不报）

- 仅语法错误回显但不可利用
- WAF 完全阻断且无绕过证据
- 二次编码猜测无稳定路径

## 记录要求

- 完整 URL、方法、关键参数  
- 响应差异或 OOB 记录  
- 影响说明必须达到 Critical/High
