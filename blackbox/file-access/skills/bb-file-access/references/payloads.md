# File Access 最小验证提示

> 仅用于已授权验证。不要构建完整攻击框架。

## 探测方向

- download/export/preview 路径参数
- ../ 与编码绕过
- 上传点: 图片/附件/导入
- 解压/文档转换接口

## 合格证据

- 任意文件读到密钥/代码/云凭证
- 任意文件写导致 RCE
- 上传 webshell 或可执行内容

## 不合格（不报）

- 仅读到公开静态资源
- 上传仅存对象存储且不可执行、不可覆盖关键配置

## 记录要求

- 完整 URL、方法、关键参数  
- 响应差异或 OOB 记录  
- 影响说明必须达到 Critical/High
