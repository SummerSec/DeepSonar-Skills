# ai-agent — AI / LLM / Agent 类漏洞定义

## 1. 何时使用

目标含下列任一组件，且 finding 的 **根因** 落在「模型上下文」或「模型可调用的工具」语义内：

- 对话式助手 / 智能体（Agent）/ Bot / Copilot / 工作流编排
- 提示词、技能配置、工具清单（tool schema）、MCP 服务、函数调用
- Agent 记忆（memory）、会话历史、附件解析、知识库与向量检索
- Agent 执行环境（代码解释器、构建容器、浏览器沙箱）

判据：**攻击者可控输入的作用对象是「模型读写的上下文」或「模型可调用的工具」**，而不是服务端解析器（SQL / shell / 模板引擎）。

---

## 2. 漏洞定义是什么

**AI / Agent 类漏洞**：攻击者通过 **模型上下文**（提示词、附件、检索内容、工具回包）或 **工具调用通道**，越过「本次会话」与「本租户」的边界，取得数据、凭据或执行能力。

### 形态表

| # | 形态 | 典型机理 | 常见 CWE |
|---|------|----------|----------|
| A1 | 提示词注入 → 敏感面 | 直接 / 间接（附件、检索、网页）/ 跨用户注入，驱动助手读取云凭证、跨用户数据，或操控平台 Bot | CWE-1427 |
| A2 | 内部规则外泄 | system prompt、技能配置、工具清单 / schema、内部业务规则被对话诱导输出 | CWE-1427 / CWE-200 |
| A3 | 工具 / MCP 越权调用 | 普通用户调用未上架内部 MCP 或内部工具；工具回包（ToolResult）泄漏服务器文件或内部数据 | CWE-306 / CWE-862 |
| A4 | 记忆 / 会话 / 附件跨用户读写 | 记忆文件读取工具跨用户越权、他人会话历史可读、附件与向量库跨租户检索 | CWE-639 / CWE-284 |
| A5 | 资源与计费 / 风控滥用 | 无限使用模型资源、绕过风控与付费产品、匿名领取权益绕过准入 | CWE-770 / CWE-799 |
| A6 | 执行环境隔离失效 | 构建容器逃逸、全平台用户共享执行容器、沙箱内硬编码云凭据 | CWE-653 / CWE-798 |
| A7 | 提示词 / 编排参数注入 → 服务端代码执行 | 攻击者通过自有应用 / 工作流可编辑的节点参数（如结果后处理开关 `post_process='to_json'` 与强制非流式 `stream=false` 的组合）、提示词模板或检索内容，使 **LLM 输出或模型后处理函数进入服务端执行语义**（`eval` / `exec` / 表达式引擎 / 解释器）。**成立必须同时满足**：① 攻击者控制至少一个进入模型上下文或编排配置的参数通道（含「保存 → 发布 → 存档下发」链路）；② 该参数通道不在保存 / 发布闸门的校验字段集内，或校验可被值域外取值绕过；③ 存在 LLM 逐字回显或等效可控转发通路（证据：few-shot 反射协议、回显一致性探针）；④ 转发输出或后处理函数到达执行 sink。**执行宿主不论沙箱与否**：常驻业务进程、代码解释器、任务容器均计。**定级不归本表**：主类型与四档一律取 `rce.md`（`#C2` / `#C3`） | CWE-94 / CWE-95 / CWE-1427 |

### 前提轴（固定四值）

| 值 | 含义 |
|----|------|
| 未认证 | 无任何会话即可触达 |
| 普通用户 | 已登录的普通账号（同租户自身） |
| 同租户他人 | 同租户内其他用户 / 其他会话的数据或能力 |
| 跨租户 | 越过租户或组织边界 |

**成立必要条件（同时满足）**：

1. 存在攻击者可控的上下文输入，或存在可被调用的工具 / 执行环境
2. 上下文或工具通道缺少边界校验（会话隔离、租户隔离、工具白名单、凭据下发）
3. 攻击者实际取得 **不应有的数据、凭据或能力**

**不覆盖（边界）**：

- 模型输出仅为文本回显，不经工具与数据面 → `none`（见 N1）
- 注入点落到 SQL / shell / 模板引擎等传统解析器 → 主类型取 `injection.md`
- 凭据泄露本身即根因（前端包硬编码 AK、配置文件泄露）→ 主类型取 `secrets.md`
- 仅为模型生成内容不准确、不达预期 → 不是安全漏洞
- 模型越狱（jailbreak）只改变自身会话的输出内容，不影响他人与平台 → N2

## 3. 严重（Critical）

| # | 判定条件 |
|---|----------|
| C1 | 未认证或普通用户经提示词注入 / 工具调用取得 **云凭证、生产密钥**，或跨租户读写数据 |
| C2 | Agent 执行环境（代码解释器 / 构建容器 / 浏览器沙箱）隔离失效，可读他人文件、跨用户执行或逃逸到宿主 |
| C3 | 记忆 / 会话 / 附件 / 向量库可跨用户读取，且内容含 **受限数据**（金融画像、证件、健康、私信、支付信息） |

---

## 4. 高危（High）

| # | 判定条件 |
|---|----------|
| H1 | 可外泄 system prompt、技能配置、工具清单 / schema 或内部业务规则，且据此可构造进一步利用 |
| H2 | 未上架内部 MCP / 工具可被普通用户调用，且具备 **写或执行** 能力 |
| H3 | 可绕过计费、额度或风控，无限使用模型 / 智能体资源，造成可计量成本损失 |
| H4 | 可操控他人 Bot / 智能体执行对外动作（发布、外呼、工单、通知），以他人名义生效 |
| H5 | 跨用户写入记忆 / 知识库 / 向量库，影响他人后续会话的业务判断 |

---

## 5. 中危（Medium）

| # | 判定条件 |
|---|----------|
| M1 | 提示词或工具清单泄露，**无可进一步利用面**（无内部凭据、无越权路径） |
| M2 | 可读取他人 AI 会话或记忆，但内容为 **低敏**（公开内容、无身份与业务字段） |
| M3 | 计费 / 额度绕过仅影响自身账号，无平台级成本或风控影响 |

---

## 6. 无危害（None）

| # | 判定条件 |
|---|----------|
| N1 | 模型输出不经工具与数据面，仅文本回显，无越权与泄露 |
| N2 | 提示词注入仅改变 **自身会话** 输出，不影响他人、工具与平台 |
| N3 | 执行环境内无凭据、无跨用户数据面，隔离成立 |
| N4 | 工具调用有租户 / 会话隔离校验，且回包不含他人数据 |
| N5 | 注入通道与回显通路均存在，但 **执行 sink 不成立**（后处理仅 `json.loads`、返回值仅做文本展示），或 **逐字回显未被证实**（模型对特殊字符必需的复制协议不可用）；与 `rce.md#N4` 同义 |

---

## 7. 与其它类型的边界

| 情形 | 主类型 |
|------|--------|
| 注入点落在 SQL / shell / 模板引擎 / 反序列化，或 A7 形态中 LLM 输出 / 后处理到达服务端执行 sink | `injection.md` / `rce.md` / `deserialization.md`；**A7 按根因取 `rce.md`**（主类型与四档唯一归 `rce.md#C2` / `#C3`，本类型仅提供形态与污点通路要件） |
| 泄露的凭据本身即根因（前端硬编码、桶可读） | `secrets.md`；利用面另开 finding |
| 服务端出站请求被诱导致内网 / metadata | `ssrf.md`（云资源暴露面见 `cloud-native.md`） |
| 无鉴权管理接口 / IDOR，与模型语义无关 | `authz.md` |
| 组件默认配置或 CVE（含 AI 框架自身漏洞） | `component.md` |

---

## 8. 白盒 / 黑盒证据要点

| | 白盒 | 黑盒 |
|--|------|------|
| 最低 | 用户输入与工具回包同进上下文，无隔离与出参过滤；A7 另需证明「参数通道 → 模型逐字回显 → sink」通路 | 可复现的输出改变或工具调用差异；A7 另需回显一致性 + 时延 / 输出旁证 |
| Critical | 工具可直接读凭证 / 跨用户数据源，且无租户参数校验 | 实际读出云凭证明文或他人记忆内容 |
| 常见 none | 上下文仅含服务端常量；工具需服务端签名 | 输出异常但无越权、无泄露、无状态变更 |
