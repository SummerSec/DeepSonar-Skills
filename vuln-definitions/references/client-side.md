# client-side — 客户端注入与跨域类漏洞定义

## 1. 何时使用

目标为浏览器侧或 WebView 内的代码执行 / 跨域信任问题，**根因在客户端渲染或跨窗口消息处理**：

- XSS（反射 / 存储 / DOM）、UXSS、mXSS
- `postMessage`、`window.opener`、WebView 桥（JSBridge）消息处理
- CORS 响应头配置、跨域凭据读取
- 开放重定向 / 任意 URL 加载、点击劫持与界面伪造

判据：**定档锚点是「能否取得会话、能否跨域执行、能否链到可接管凭据」**；「能弹窗」本身不作定档依据。

---

## 2. 漏洞定义是什么

**客户端注入 / 跨域缺陷**：攻击者可控内容在 **受害者浏览器上下文** 中被当作脚本执行，或跨窗口 / 跨域信任配置缺校验，导致在他人会话中执行代码、读取凭据或驱动敏感操作。

| 子类 | 含义 | 常见 CWE |
|------|------|----------|
| XSS（反射 / 存储 / DOM） | 可控内容进入 HTML / JS 执行上下文 | CWE-79 |
| UXSS / 跨域执行 | 借助解析缺陷或插件在其它源执行脚本 | CWE-79 |
| 消息通道缺校验 | `postMessage` / JSBridge 无 `origin` / `source` 校验 | CWE-346 |
| CORS 信任过宽 | 反射任意 `Origin` 且 `Allow-Credentials: true` | CWE-942 |
| 开放重定向 / 任意 URL 加载 | 跳转目标可控，可外带授权码或凭据 | CWE-601 |
| 点击劫持 / 界面伪造 | 无 `frame-ancestors` 等，诱导用户完成敏感操作 | CWE-1021 |

**成立必要条件**：

1. 攻击者可控输入进入 **脚本执行上下文** 或 **跨域信任判定**
2. 受害者会话可被触达（链接、他人可写页面、第三方站点、消息发送方）
3. 造成凭据读取、跨域执行、敏感状态变更或可接管链路

**不覆盖（边界）**：

- 仅攻击者自己在自己会话中看到的注入（self-XSS）→ M1
- 服务端模板拼接且输入进入服务端解析语义 → `injection.md`
- 移动端 App 应用层 WebView / URL Scheme 形态 → `vuln-definitions-mobile`（机理主类型仍可填本类）
- 纯前端展示缺陷（错位、溢出、UI 变形）→ 不是安全漏洞

---

## 3. 严重（Critical）

| # | 判定条件 |
|---|----------|
| C1 | XSS / UXSS 可读取会话凭据（Cookie、localStorage token）或同源可接管凭据，且可在 **其他用户会话** 稳定触发 |
| C2 | `postMessage` / WebView 桥在无 `origin` 校验下可调用 **特权能力**（改密、绑定、转账、执行代码），可导致账户接管或代码执行 |
| C3 | 开放重定向链到 OAuth 授权码 / token 外带，可完成账户接管 |

---

## 4. 高危（High）

| # | 判定条件 |
|---|----------|
| H1 | 存储型 XSS 在其他用户会话稳定触发，但未演示凭据读取 |
| H2 | DOM XSS 位于认证后页面，可读取当前用户敏感数据或驱动敏感操作 |
| H3 | UXSS / 跨域执行影响同主域下的敏感子域（凭据域、控制台域） |
| H4 | CORS 反射任意 `Origin` 且带凭据，可跨站读取登录态接口响应（同一根因只报一条：**响应头配置**为主 → `authz.md#H7`；由客户端脚本或消息通道引入 → 本条） |
| H5 | 开放重定向 / 任意 URL 加载发生在登录或支付流程内，可诱导凭据提交到攻击者域 |

---

## 5. 中危（Medium）

| # | 判定条件 |
|---|----------|
| M1 | 反射型 XSS 需受害者手动构造（self-XSS）或仅自身会话可触发 |
| M2 | 开放重定向单独存在：无凭据外带、不在登录 / 支付流程内 |
| M3 | 点击劫持 / 界面伪造，无凭据捕获、无资金或权限状态变更 |
| M4 | 消息通道无 `origin` 校验，但可达回包无敏感数据、无可触发的状态变更 |

---

## 6. 无危害（None）

| # | 判定条件 |
|---|----------|
| N1 | CSP 与输出编码均正确，无可绕过路径 |
| N2 | 重定向目标为严格白名单，编码 / 后缀 / 解析差异均不可绕过 |
| N3 | 注入点仅输出到非脚本上下文（纯文本、JSON、CSS 属性）且无脚本执行语义 |
| N4 | 消息通道校验 `origin` 与 `source`，且仅传递非敏感数据 |

---

## 7. 白盒 / 黑盒证据要点

| | 白盒 | 黑盒 |
|--|------|------|
| 最低 | 可控 source → DOM sink（`innerHTML` / `document.write` / `eval`） | 可复现脚本执行（`alert` 等价物或自定义回调） |
| Critical | sink 可达 cookie / token，且页面在他人可写链路中 | 实际读出他人会话 token 或完成接管链路 |
| 常见 none | 框架自动编码且无绕过；跳转白名单 | 注入仅在自身浏览器手工构造时生效 |
