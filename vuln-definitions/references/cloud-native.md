# cloud-native — 云资源与编排面暴露类漏洞定义

## 1. 何时使用

缺陷的 **根因是云资源自身策略或编排 / 运行时隔离**，而不是应用解析逻辑：

- 对象存储桶策略、STS / 临时凭据作用域、密钥管理
- 云 metadata 可达性与 IMDS 配置
- Kubernetes / Kubelet / 编排面未授权、ServiceAccount 作用域
- 容器与沙箱隔离（共享运行时、逃逸、跨用户复用）
- 制品仓库 / 镜像仓库的写权限

判据：**修复方式是改云侧策略、编排权限或运行时隔离**，而不是改应用代码。

---

## 2. 漏洞定义是什么

**云资源与编排面暴露**：**匿名身份或低权限身份**（含合法但受限的租户 / 角色 / ServiceAccount）取得 **未授权** 的云资源、编排面或运行时能力，或取得可放大为资源接管的凭据。

| 子类 | 含义 | 常见 CWE |
|------|------|----------|
| 存储与密钥策略 | 桶 / 密钥可匿名读写；STS 作用域覆盖越界 | CWE-732 / CWE-284 |
| metadata 可达 | 元数据服务可读且可取出有效凭据 | CWE-918 / CWE-522 |
| 编排面未授权 | K8s API / Kubelet / 控制面端点无认证可操作 | CWE-306 |
| 运行时隔离 | 共享容器、跨用户复用、容器逃逸 | CWE-653 / CWE-269 |
| 制品供应链 | 私有源、镜像仓库可写可投毒 | CWE-494 |

**成立必要条件**：

1. 云资源 / 编排端点 / 运行时网络可达
2. 策略或隔离缺位（匿名允许、RBAC 过宽、跨账号信任关系过宽、命名空间不分租户、共享沙箱）
3. 攻击者实际取得 **超出其已有身份** 的越界数据、凭据或执行能力

**不覆盖（边界）**：

- 应用侧主动发起的出站请求被诱导致内网 → `ssrf.md`（本类只管云资源自身暴露）
- 泄露凭据本身即根因、且无云侧策略缺陷 → `secrets.md`
- 云厂商自身的公开元数据、公开桶（设计上公开）→ `none`
- 攻击者已是云账号管理员 / 集群管理员 → 不在威胁模型；但 **低权限身份越权到管理员 / 跨账号** 属于本类（前提轴写「低权限身份」）

---

## 3. 严重（Critical）

| # | 判定条件 |
|---|----------|
| C1 | 未认证可达的编排面 / 元数据 / 存储管理接口，可读写任意对象或取得集群凭证 |
| C2 | 容器 / 沙箱可逃逸到宿主，或运行时被跨租户共享，可读写他人文件与进程 |
| C3 | 取得的云凭据可创建资源、读全量密钥（IAM / KMS / STS 越权） |

---

## 4. 高危（High）

| # | 判定条件 |
|---|----------|
| H1 | 未授权可读敏感对象存储桶 / 只读集群数据（非公开数据、非全量凭据） |
| H2 | metadata 可达并取得凭据，但凭据利用未完成或作用域受限 |
| H3 | 制品 / 镜像仓库可写，可向生产部署链路投毒 |
| H4 | 编排面只读未授权，可枚举工作负载、密钥引用与内部拓扑 |

---

## 5. 中危（Medium）

| # | 判定条件 |
|---|----------|
| M1 | 未授权可枚举桶名、云账号 ID、节点列表等低敏元数据 |
| M2 | 沙箱内硬编码凭据仅能访问攻击者自身租户的资源 |
| M3 | 编排面未授权但仅暴露版本、健康检查等非敏感端点 |

---

## 6. 无危害（None）

| # | 判定条件 |
|---|------|
| N1 | 元数据访问有强制 IMDSv2 / hop limit 限制，且无其它可达路径 |
| N2 | 桶 / 资源策略对 **所有未授权身份** 均拒绝（含匿名、其它租户凭据、低权限角色的越界动作），而不只是拒绝匿名 |
| N3 | 可触达资源仅限攻击者自身租户，无跨边界语义 |
| N4 | 端点可达但需 **作用域相符** 的凭据；低权限身份无法通过该端点提升或跨账号 |

---

## 7. 与其它类型的边界

| 情形 | 主类型 |
|------|--------|
| 应用出站请求被诱导（webhook、URL 预览） | `ssrf.md` |
| 硬编码 AK/SK 暴露，无云侧策略缺陷 | `secrets.md` |
| 云侧策略允许匿名写 + 应用侧泄露路径 | `secrets.md`（泄露）与 `cloud-native.md`（策略）各一条 |
| 组件自身 CVE 导致容器逃逸 | `component.md` 记可达性，本类记隔离失效 |

---

## 8. 白盒 / 黑盒证据要点

| | 白盒 | 黑盒 |
|--|------|------|
| 最低 | IaC / 策略文件允许匿名、其它租户或低权限角色执行越界动作 | 无凭据 **或低权限凭据** 请求返回越界数据（匿名被拒但跨租户 / 降权凭据可读同样合格） |
| Critical | 集群凭证可读，或运行时跨用户共享 | 实际读写他人对象或取得集群凭证 |
| 常见 none | 桶策略拒绝全部未授权身份、IMDSv2 强制 | 匿名与低权限 / 跨租户凭据均被拒（403 / 需签名且作用域不匹配） |
