# xxe — XML 外部实体定义

## 1. 漏洞定义是什么

**XXE（XML External Entity）**：XML 解析器在处理不可信 XML 时允许 **外部实体/DTD**，导致攻击者读取本地文件、发起 SSRF，或在极端情况下结合其它特性造成更严重后果。

相关：XInclude、参数实体盲注。CWE-611。

**成立必要条件**：

1. 解析不可信 XML（上传、SOAP、SAML、办公文档内 XML 等）  
2. 解析器启用了危险特性（外部实体、DTD）  
3. 可观察到文件内容、OOB、或内网请求等效果  

---

## 2. 严重（Critical）

| # | 判定条件 |
|---|----------|
| C1 | 可读取 **密钥/云凭证/私钥/生产配置** 文件内容 |
| C2 | XXE 转 SSRF 拿到 **metadata 凭证** 或内网沦陷证据 |
| C3 | 结合环境实现 **RCE**（少见，需证据） |

---

## 3. 高危（High）

| # | 判定条件 |
|---|----------|
| H1 | 可读取系统/应用 **敏感文件**（如 `/etc/passwd`、应用配置非密钥）证明任意读 |
| H2 | 盲 XXE + OOB 稳定外带 **敏感数据片段** |
| H3 | 可 SSRF 内网管理端口并读到敏感响应 |

---

## 4. 中危（Medium）

| # | 判定条件 |
|---|----------|
| M1 | 外部实体开启，但只能读 **无敏感** 文件或 OOB 仅证明可解析 DTD |
| M2 | 仅 DoS（billion laughs）— 本仓默认 **不关注纯 DoS**，可记 medium 或 none |
| M3 | 需管理员上传 XML 且数据面有限 |

---

## 5. 无危害（None）

| # | 判定条件 |
|---|----------|
| N1 | 解析器 **禁用 DTD/外部实体**（`setFeature` / `defusedxml` / 安全默认） |
| N2 | 不接受 XML，或只解析可信内部 XML |
| N3 | 上传的 XML 当纯文本存储 **从不解析** |
| N4 | 扫描器塞入 XXE payload 无差异，解析器忽略实体 |

---

## 6. 白盒 / 黑盒证据要点

| | 白盒 | 黑盒 |
|--|------|------|
| 最低 | XML parser 配置危险 | 回显文件内容或 OOB |
| Critical | 无安全 flag + 用户 XML 入口 | 读出密钥文件 |
| none | `disallow-doctype-decl` 等正确 | payload 无效果 |
