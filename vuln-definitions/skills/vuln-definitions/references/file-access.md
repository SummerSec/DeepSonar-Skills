# file-access — 文件访问与危险上传定义

## 1. 漏洞定义是什么

**文件访问类缺陷**：路径、文件名或上传内容由攻击者影响，导致：

- **任意文件读**（路径遍历、未授权读）  
- **任意文件写**（遍历写、覆盖配置）  
- **危险文件上传**（可执行内容、webshell、覆盖启动脚本）  

常见 CWE：CWE-22、CWE-73、CWE-434、CWE-59（链接攻击）。

**成立必要条件**：

1. 路径或文件内容存在攻击者控制面  
2. 校验不足（未规范化、未限制根目录、扩展名/内容可绕过）  
3. 实际读/写/执行了 **超出授权** 的对象  

---

## 2. 严重（Critical）

| # | 判定条件 |
|---|----------|
| C1 | **任意文件读** 到密钥、私钥、云凭证、生产配置、数据库连接串 |
| C2 | **任意文件写** 可覆盖 web 根/启动脚本/计划任务 → RCE |
| C3 | 上传 **可执行 webshell** 或服务端会执行的脚本，并成功访问 |
| C4 | Zip Slip 等解压写出到关键路径导致沦陷 |

---

## 3. 高危（High）

| # | 判定条件 |
|---|----------|
| H1 | 任意文件读到 **大量业务敏感数据**（用户数据文件、备份）但非直接密钥 |
| H2 | 上传绕过存到 **可被解析执行** 的位置（差一步）或可覆盖 **重要业务文件** |
| H3 | 可读 `/etc/passwd` 等系统文件证明遍历，向敏感文件扩展路径清晰 |
| H4 | 写文件不在 webroot，但可污染 **模板/计划导入路径** 形成高影响链 |

---

## 4. 中危（Medium）

| # | 判定条件 |
|---|----------|
| M1 | 遍历只能读到 **应用公开静态目录** 内其它无敏感文件 |
| M2 | 上传类型限制可部分绕过，但文件存 **不可执行对象存储**，不可覆盖、不可 XSS 到管理会话 |
| M3 | 仅文件名异常导致错误，无读到非授权内容 |
| M4 | 需管理员才能上传，且执行面不存在，仅存储污染 |

---

## 5. 无危害（None）

| # | 判定条件 |
|---|----------|
| N1 | 路径经 `realpath` + 根目录前缀校验，越界拒绝 |
| N2 | 下载 ID 映射服务端对象，用户不碰路径 |
| N3 | 上传白名单扩展名 + 随机名 + 非执行存储 + 不回源执行 |
| N4 | 用户只能读自己的对象存储 key 且签名有效 |

---

## 6. 白盒 / 黑盒证据要点

| | 白盒 | 黑盒 |
|--|------|------|
| 最低 | 拼接路径 `open(user_path)` | `../` 读到非授权内容 |
| Critical | 可写 webroot 或读密钥路径 | 读到密钥 / 上传执行成功 |
| none | `safe_join` 正确 | 遍历返回 400 |
