# 级别调整与非安全条款

定级后必须过本文件：命中调整条款 → 下调；命中无效条款 → 直接停。  
口径：Severity Guidelines 文首缓解规则 + Security FAQ + [Chrome VRP Rules](https://bughunters.google.com/about/rules/chrome-friends/chrome-vulnerability-reward-program-rules) / VRP FAQ 的范围排除。  
赏金资格细则见 `vrp-rules.md`，**不**用奖金表改档。

---

## 一、级别调整（官方缓解，通常降一档或更多）

| # | 条款 | 对本模块含义 | 实战处理 |
|---|------|--------------|----------|
| ADJ1 | **非网页可达，只能靠直接 UI 操作触发** | 没有网页/远程内容路径 | 降一档或更多；纯本机点点点且无网页入口 → 常非模型 |
| ADJ2 | **罕见或不太可能的用户交互** | 平均用户用该功能时不典型，网页也难以说服其去做（但并非完全荒唐） | **通常降一档** |
| ADJ3 | **必须毁掉 profile 或关掉浏览器** | 官方明文通常降一档 | 以此为前提的洞 **最高 High**；还可被其它缓解再降（L4/L5） |
| ADJ4 | **MiraclePtr 保护** | `MiraclePtr Status: PROTECTED` | **直接非安全**（见 INV1），不是降档 |
| ADJ5 | **本应更高，但前提极端** | 特定扩展、非标准旗标、debugger 权限、特定手势 | 落到 M2/M3/L3/L6，不要留在 C/H |
| ADJ6 | **独立沙箱 Metal 着色器编译器** | 只打到 `MTLCompiler` | 本应 High → **Medium（M4）** |
| ADJ7 | **Security-Impact_None** | 实验、原型、未默开启、部分用户旗标 | **仍定级**；不走 30/60 天 SLO；出货前应修 |
| ADJ8 | **只影响部分用户** | 仅 Linux、仅开了无障碍等 | **不降档**（官方反例：这不是缓解） |
| ADJ9 | **链上的单洞** | 完整出沙箱链可以是 Critical | 单洞按自身档；不要每环都标 C3 |
| ADJ10 | **野外利用 / 武器化** | 正在被打 | **不改档**，只把修复优先级提到 P0 / 7 天 |

**命中判定**：新发现先自查是否踩中缓解；踩中 → 降档或改 INV，写明条款号。

### 交互：罕见 vs 不合理

| 交互 | 处理 |
|------|------|
| 授予一项常见权限、普通点击导航 | **常见**，可支撑 H6 / C1 |
| 偶尔会发生、但不是该功能典型路径 | **罕见** → ADJ2 降一档 |
| 普通用户不会做、网页也劝不动 | **不合理** → INV8，功能缺陷 |
| 必须先关浏览器 / 毁掉 profile | ADJ3，封顶 High |
| 连点、按住键的 clickjacking | 仍是 L18；再复杂 → INV8 |

## 二、无效 / 非安全（命中即停）

| # | 条款 | 实战处理 |
|---|------|----------|
| INV1 | **MiraclePtr PROTECTED** | 改功能缺陷；ASAN 须带 Status 段 |
| INV2 | **仅检出悬空指针、未解引用损坏** | 须无 `dangling_ptr` 专用旗标的 ASAN 崩溃才能当漏洞 |
| INV3 | **纯 DoS / 稳定性** | 标签页崩、CHECK、卡死、站点不让离开 → 滥用/稳定性，**不是**安全漏洞，也不走 VRP |
| INV4 | **空指针 + 一致的小固定偏移** | ≤32KB（官方「NULL page」）不当漏洞；**大于 32KB 或偏移是否可控存疑 → 仍评** |
| INV5 | **普通栈溢出** | guard page 视为不可利用（=DoS）；能跳过 guard（超大帧 / 可控 `alloca` / VLA）才评 |
| INV6 | **tint ICE** | 编译器主动失败并退出、无着色器输出 → 非安全 |
| INV7 | **物理本机 / 同 OS 用户已控 / 已中毒机器** | 投放 DLL、hook、改 PATH、调试端口敞开 → 不在威胁模型 |
| INV8 | **不合理交互** | 见上表；复杂 clickjacking 手势也走这里 |
| INV9 | **隐私 / 指纹 / Incognito** | 隐私组当功能缺陷；**不是**安全 VRP |
| INV10 | **站点自身 XSS / XSS 过滤器绕过** | XSSAuditor 已删；站点洞不是 Chrome 洞 |
| INV11 | **无安全决策的 UI 欺骗** | 骗复制、骗下载、骗导航；理性用户不会做错安全决策 |
| INV12 | **测试二进制 / 测试发行版** | `unit_tests` / `browser_tests`；CfT / headless-shell 打不可信网 |
| INV13 | **Safe Browsing 尚未收录 / 预加载列表未同步** | 功能延迟，不是漏洞；插页被**绕过**才走 M7 |
| INV14 | **File System Access 黑名单被用户点选绕过** | 防误点纵深，明确选择不当漏洞 |
| INV15 | **企业策略被本机用户绕过** | FAQ：一般不是安全洞 |
| INV16 | **javascript: / DevTools / 书签脚本** | 用户对自己文档执行脚本，不是 XSS |
| INV17 | **仅理论、无 PoC** | VRP：静态分析猜想且无演示 → 不可复现 / WontFix |
| INV18 | **其它应属非安全** | 兜底：时序侧信道多数走隐私；仅观察到 NTLMv2 响应等 |
| INV19 | **AI 越狱 / 幻觉 / 对齐 / 仅系统提示词** | 模型输出不当、自己会话越狱、拷贝粘贴提示词、仅 preamble 泄漏 → 产品反馈或 Google Abuse/VRP，**不是** Chrome 安全洞。间接触发未确认有害动作或敏感数据外带才评（A1/A2） |

**复现硬门槛**：出货通道（Stable / Beta / Dev）+ 默认可达或已出货给部分用户的配置；内存安全须 **符号化 ASAN**（含 MiraclePtr Status）。  
只在 Canary / 落地未满约 7 天的 HEAD 新代码上成立 → `vrp_eligible: false`，定级可记但对内。

## 三、强前提迁出清单

以下任一成立，视为「强前提」，不进可报队列，按非安全或降到已证影响：

| 类型 | 例子 |
|------|------|
| 身份前提 | 必须已是同一 OS 用户、已 root、已装恶意 DLL |
| 链式前提 | 必须再叠一个未证明的 renderer RCE 才谈 C3（已沦陷 renderer 本身是合法前提） |
| 环境前提 | `--single-process`、unsafe 警告旗标、仅测试二进制 |
| 场景过窄 | 不合理交互、必须毁掉 profile 且还很难触发（L4） |
| 缓解后不可利用 | MiraclePtr PROTECTED |
| 证据未闭合 | 无符号化 ASAN；只写「可能损坏」 |
| 版本前提 | 仅未出货 HEAD、现网 Stable 已修 |

## 四、与 OH 插件条款的差异（避免串台）

| 点 | Chrome | OpenHarmony |
|----|--------|-------------|
| 第四档 | 低危 `low`（S3） | 低危 `low` |
| 纯 DoS | **非安全** | 远程临时 DoS 可高危；本地临时可低危 |
| 「本地 App」模型 | **不是**主模型（同用户本机常 INV） | 普通三方 HAP 是合法本地模型 |
| 已沦陷 renderer | 合法 High 前提 | 无对应概念；二次洞常 ADJ4 |
| 只影响部分用户 | **不降档** | 特定版本/非核心可 ADJ2 |
