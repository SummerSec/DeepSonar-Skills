# Chrome / Chromium 浏览器漏洞类型定义

本文件定义 **浏览器攻击面形态**，用于：

- 审计时「洞落在哪一类浏览器面」
- 与 `severity-levels.md` 交叉：先定形态，再定档
- 与 `vuln-definitions` 八类交叉：本文件偏 **浏览器落点**，八类偏 **利用语义**

**纪律**：只写类型与判定规则；**不写**具体 CVE、crbug、历史样板 ID。  
定级以 `severity-levels.md` + `adjustment-and-invalid.md` 为准；本文件不单独抬级。

---

## 0. 怎么用

1. 先定 **攻击者**：网页内容，或已沦陷 renderer
2. 先定 **进程与沙箱**（`process-sandbox.md`）
3. 在本文件命中 **形态**（可多选，取危害最高且证据充分的）
4. 用类型表中的 **条款倾向** 打开 `severity-levels.md` 精匹配
5. 过 Gate 与 ADJ/INV
6. 回填 `chrome_class` + `vuln_type`

## 1. 进程边界与沙箱（P）

| ID | 类型 | 定义（是什么） | 不是什么 | 路径 | 条款倾向 |
|----|------|----------------|----------|------|----------|
| P1 | **网页直达未沙箱高权进程** | 网页内容不经 renderer 沦陷即可打到 browser / 未沙箱 GPU / 未沙箱 network 的内存破坏 | 必须先 MojoJS / 已沦陷 renderer | 网页 | **C1 / C2** |
| P2 | **沙箱内任意代码** | renderer / 已沙箱 GPU / 其它沙箱进程内 ACE | 出沙箱；仅崩溃 | 网页 | **H1 / H3** |
| P3 | **OS 沙箱逃逸** | 已沦陷 renderer 触发高权未沙箱进程或内核内存破坏，从而拿到用户权限 | iframe/CSP sandbox；只削弱沙箱 | 已沦陷 renderer | **H4 / H7 / H8** |
| P4 | **沙箱削弱未逃逸** | 降低沙箱有效性，但不能在沙箱外执行 | 完整逃逸 | 网页或已沦陷 renderer | **L9** |
| P5 | **跨用户 / 系统提权** | 标准安装、无前提，打破 OS 用户边界或提到 SYSTEM/root | 已是同用户本机；企业管理员预期能力 | 本地（相对 OS） | 系统提权 **H13**；破用户边界 **M9** |
| P6 | **内核逃逸面** | 内核内存破坏可被已沦陷 renderer 用作逃逸 | 仅 oops 无利用路径 | 已沦陷 renderer | **H7** |

## 2. 内存安全与引擎（M）

| ID | 类型 | 定义 | 不是什么 | 路径 | 条款倾向 |
|----|------|------|----------|------|----------|
| M1a | **Browser 内存破坏** | browser 进程 UAF / OOB / 竞态等 | MiraclePtr PROTECTED；空指针小固定偏移 | 网页 → C1；已沦陷 renderer → H4；关浏览器封顶 High | C1 / H4 / H6 / L4 / L5 |
| M2a | **Renderer / Blink 内存破坏** | 排版、DOM、绑定、Paint 等 renderer 内损坏 | 仅 renderer 自杀式 CHECK | 网页 | ACE → **H1**；OOB 读 → L2；特定手势 → L3 |
| M3a | **V8 内存破坏 / 可利用正确性** | 引擎内存破坏，或 DCHECK 正确性失败可导向利用 | 不同编译层结果不一致（那是 M4a）；实验旗标专属 | 网页 | **H2** |
| M4a | **V8 分层正确性** | 不同编译层返回不同结果 | 已证 ACE | 网页 | **M1** |
| M5a | **受控跨进程读** | 已沦陷 renderer 从 browser/GPU/network **受控**读 ≥16 字节 | 不受控未初始化、单字节 | 已沦陷 renderer | **H5**；不受控未初始化 → **L7**；单字节 → **L1** |
| M6a | **未初始化 / 小泄露** | 不受控单字节、renderer 任意 OOB 读、未初始化经 IPC | 受控 ≥16B | 视进程 | L1 / L2 / L7 |
| M7a | **MiraclePtr / 悬空指针检测** | ASAN `PROTECTED`，或仅检出悬空未解引用 | `NOT PROTECTED` 且可证损坏 | — | **INV**（功能缺陷） |

ASAN：renderer 里的 READ 除非明确是小尺寸读，否则按 WRITE 处理。

## 3. Web 平台、源与隔离（W）

| ID | 类型 | 定义 | 不是什么 | 路径 | 条款倾向 |
|----|------|------|----------|------|----------|
| W1 | **通用 XSS / 完全 SOP 绕过** | 在任意源上下文执行脚本 | 站点自己的 XSS（站点漏洞，不是 Chrome） | 网页 | **H9** |
| W2 | **Site Isolation：错进程** | 跨站执行上下文共享同一 renderer | 同站多页面同进程（预期） | 网页 | **H10** |
| W3 | **Site Isolation：跨站数据** | 跨站数据泄露到攻击者源或攻击者进程 | 仅公开资源；隐私指纹 | 网页 | **H11** |
| W4 | **有前提的 SOP 绕过** | 绕过 SOP 但页面须满足多项前提 | 无前提 UXSS | 网页 | **M6** |
| W5 | **HSTS 绕过** | 绕过 HSTS 升级/锁定 | 预加载列表尚未同步（非安全） | 网页 | **M5** |
| W6 | **安全插页绕过** | 任意页绕过恶意软件/证书等插页 | Safe Browsing 尚未收录某站 | 网页 | **M7** |
| W7 | **部分 CSP 绕过** | CSP 部分失效，未到任意源执行 | 完全 SOP/UXSS | 网页 | **L11** |
| W8 | **用户手势绕过** | 无手势完成本应手势门控的敏感动作 | 复杂连点骗点（L18 / 可用性） | 网页 | **L10** |
| W9 | **浏览历史推断** | 稳定读或推断历史 | 指纹/隐私侧写 | 网页 | 完整 → **M8**；有限 → **L15** |

站点自己的存储型/反射型 XSS **不是** Chrome 漏洞。XSSAuditor 已移除，绕过 XSS 过滤器不是安全洞。

## 4. Mojo、IPC 与已沦陷 renderer（I）

| ID | 类型 | 定义 | 不是什么 | 路径 | 条款倾向 |
|----|------|------|----------|------|----------|
| I1 | **Browser-side Mojo 可利用损坏** | 已沦陷 renderer 经 Mojo 打到 browser 可利用崩溃/损坏 | 仅安全 CHECK；须再叠未证明洞 | 已沦陷 renderer | **H4 / H8** |
| I2 | **高权进程受控读写** | 经官方 VRP flag / 等价方式证明对 browser/GPU/network 的受控 r/w | 理论「可能读到」 | 已沦陷 renderer | ≥16B 读 → **H5**；完整出沙箱链 → C3 |
| I3 | **错误导出 Mojo / 句柄** | 把不该给 renderer 的接口、句柄、能力授出 | 该接口本就对 renderer 开放 | 已沦陷 renderer | 按最终实害；半链不报 |
| I4 | **utility / 服务进程 Mojo** | 已沙箱 utility 被打穿 | 未沙箱 utility 且网页直达 | 视沙箱 | 沙箱内 → P2；未沙箱网页直达 → P1 |

用 MojoJS 模拟已沦陷 renderer 是官方路径。不要用自定义 harness 改 chrome 二进制来「证明」逃逸。

## 5. UX、地址栏与权限表面（U）

| ID | 类型 | 定义 | 不是什么 | 路径 | 条款倾向 |
|----|------|------|----------|------|----------|
| U1 | **地址栏源完全可控** | 攻击者完全控制 omnibox 显示的源 | 只能显示某些 URL；用户自输入未提交 URL | 网页 | **H12** |
| U2 | **有限地址栏欺骗** | 只能显示部分 URL，或另有明显缓解 | 完全控制源 | 网页 | **L13** |
| U3 | **权限/安装源欺骗** | 让理性用户把安全决策归错源（权限、装扩展） | 骗复制、骗下载、骗点无安全后果的控件 | 网页 | 能证安全决策错误 → High 向（H12 同类）或按实害；否则 INV |
| U4 | **画到浏览器 UI 上** | 网页内容覆盖浏览器铬（chrome UI） | 仅页内画布 | 网页 | **L8** |
| U5 | **其它表面 UI 欺骗** | 非 omnibox、非站点信息面板 | 无安全决策 | 网页 | **L14**；警告被挡住 → **L16**；分栏对话框 → **L17** |
| U6 | **Clickjacking / enterjacking** | 连点、按住键等骗过浏览器安全控件 | 复杂手势/多重前提 | 网页 | **L18**；复杂手势 → 可用性，非安全 |
| U7 | **历史 / 有限信息 UX** | 见 W9 | 指纹 | 网页 | M8 / L15 |

FAQ：UI 欺骗只有「野外已用来骗人」或「能让理性用户做错**安全决策**」才算安全洞。骗复制、骗下载（下载本身不是安全决策）、骗导航，默认不是。

## 6. 扩展、企业与本地组件（E）

| ID | 类型 | 定义 | 不是什么 | 路径 | 条款倾向 |
|----|------|------|----------|------|----------|
| E1 | **特定扩展才触发的内存破坏** | 必须安装某一扩展 | 所有用户默认可达 | 扩展 | **M2** |
| E2 | **debugger 权限扩展触发 browser 损坏** | 扩展已有 debugger 权限 | 普通扩展 | 扩展 | **L6** |
| E3 | **有限扩展权限绕过** | 扩展拿到略超授权的能力，未到任意代码/任意源 | UXSS、出沙箱 | 扩展/网页 | **L12** |
| E4 | **企业策略对终端用户可绕** | 用户绕过已托管策略 | 策略实现把本机提到 SYSTEM | 本机用户 | 一般 **INV**（FAQ） |
| E5 | **更新器 / 提升权限组件提权** | Chrome 组件在标准安装下无前提系统提权 | 已用管理员跑 Chrome | 本地 | **H13** |

## 7. 文件、下载与协议处理（F）

| ID | 类型 | 定义 | 不是什么 | 路径 | 条款倾向 |
|----|------|------|----------|------|----------|
| F1 | **网页读任意本地文件** | 网页内容读到任意本地路径 | File System Access 黑名单可被用户点选绕过 | 网页 | **C4** |
| F2 | **危险文件类型策略缺口** | 无需任何用户打开文件即可沦陷的新类型未进策略 | 「下了个 exe 没标红」本身 | 网页 | 能证零交互沦陷再评；否则多非安全 |
| F3 | **手势劫持骗授权/下载** | 夺用户手势骗过权限或下载确认 | 单纯下载 | 网页 | 看是否构成安全决策；复杂手势 → INV |

File System Access 黑名单是防**误点**的纵深，用户在选择器里明确选中敏感路径而绕过，官方不当安全洞。

## 8. GPU、着色器与媒体（G）

| ID | 类型 | 定义 | 不是什么 | 路径 | 条款倾向 |
|----|------|------|----------|------|----------|
| G1 | **未沙箱 GPU（网页直达）** | 网页不经 renderer 沦陷打到未沙箱 GPU | 已沙箱 GPU | 网页 | **C2** |
| G2 | **已沙箱 GPU ACE** | GPU 进程已沙箱时的内存破坏 | 仅 Metal 编译器 | 网页 | **H3** |
| G3 | **独立沙箱 Metal 着色器编译器** | 只存在于 `MTLCompiler`、仅 macOS | GPU 进程本体 | 网页 | **M4** |
| G4 | **tint ICE** | tint 主动 Internal Compiler Error 并退出 | 后续内存破坏 | 网页 | **INV** |
| G5 | **媒体 / 捕获进程** | 未沙箱 Video Capture 等 | 已沙箱 utility | 网页或已沦陷 renderer | 按该平台沙箱：直达未沙箱 → P1；否则 P2/P3 |

SwiftShader 已弃用、仅测试；WebNN 未出货加固中——VRP 常排除，定级见 `asset-scope.md`。

## 9. 网络栈与导航（N）

|----|------|------|----------|------|----------|
| N1 | **未沙箱 Network 进程损坏** | Android/Windows/Linux 上 network 未沙箱 | Mac/Fuchsia 已沙箱 | 网页直达 → **C1**；已沦陷 renderer → **H4** | **C1** / **H4** |

## 10. 与八类 `vuln_type` 的映射

| Chrome 类型（例） | 优先 `vuln_type` |
|-------------------|------------------|
| P1–P3、P6、M1a–M3a、G1–G2、I1–I2 的 ACE | `rce` |
| W1–W4、W7、H9–H11、U1 源冒充 | `authz` |
| F1、任意本地文件 | `file-access` |
| 受控跨进程读、历史、未初始化泄露 | `secrets` 少见；多仍 `rce`（利用原语）或 `authz`（跨源数据） |
| Mojo 反序列化 / 句柄 | `deserialization` 或 `rce`/`authz` 按实害 |
| 命令/表达式进引擎 | `injection` 或 `rce` |
| 扩展密钥、同步令牌可外带 | `secrets` |

现象跨类时：按 **最终可演示影响** 选一类主类型，rationale 可注明次要类。

## 11. 挖掘优先级（浏览器通用）

```
P0 网页直达未沙箱高权：browser、Android GPU、Win/Linux/Android network、任意本地文件
P1 沙箱内 ACE：V8 / Blink / 已沙箱 GPU；UXSS / Site Isolation
P2 已沦陷 renderer → 逃逸 / ≥16B 受控读 / 内核
P3 完整历史、HSTS、插页、Metal 编译器、特定扩展
P4 低危原语：OOB 读、部分 CSP、弱沙箱、有限 UX 骗
P5 通常非安全：DoS、MiraclePtr PROTECTED、物理本机、隐私指纹、测试二进制、不合理交互
```

## 12. 一票否决（浏览器向速查）

| 情况 | 处理 |
|------|------|
| MiraclePtr Status: PROTECTED | INV |
| 仅悬空指针检测、未解引用 | INV |
| 标签页崩溃 / CHECK / 纯 DoS | INV |
| 空指针且固定偏移 ≤32KB | INV |
| 普通栈溢出（没跳过 guard page） | INV |
| 物理本机 / 同用户已控 / 已中毒机器 | INV |
| 不合理、网页也劝不动的交互 | INV（功能缺陷） |
| 站点自己的 XSS、XSS 过滤器绕过 | INV |
| 隐私 / 指纹 / Incognito 保证 | INV（隐私缺陷） |
| 测试二进制 / CfT 打不可信网 | 范围外 |
| 必须再叠一个未证明洞 | 按已证单洞；链不完整不抬 C3 |
