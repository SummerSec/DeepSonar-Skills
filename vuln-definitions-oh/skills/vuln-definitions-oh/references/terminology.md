# 术语（官方口径）

| 术语 | 定义 | 挖掘时的含义 |
|------|------|--------------|
| **远程** | 不安装应用、不实际接触设备即可利用：网页浏览、短信/彩信、收发邮件、文件下载、无线网络通信等 | 最高优先；无需本地恶意 App |
| **本地** | 利用需要在受害系统安装应用，或需物理接触设备 | 允许「安装一个普通三方 HAP」的攻击者模型 |
| **TCB** | Trusted Computing Base：保护装置总体，含内核及驱动或等同内核的用户服务（如 init、vold） | 进 TCB = 严重档核心门槛 |
| **特权进程** | SELinux `system_app` 域中运行的应用/进程；system 级权限进程；root 进程 | 需要先拿到特权 → 大概率特权依赖/权限等价（无效向） |
| **普通应用进程** | 第三方应用进程，或内置但无 system 级权限的应用进程 | 攻击者应有的身份下限 |
| **受限进程** | 比普通应用进程受更严格权限约束的进程 | 本地受限进程 RCE 仅低危档 |

## 常见判定速记

- **远程 + 未鉴权 + 进 TCB / 特权数据** → 严重向
- **本地 + 仅需普通三方 HAP + 越权/隔离突破/数据读取** → 高危/中危向
- **任何「必须先 native / SA / root / 写系统路径」** → 特权依赖，直接判无效（ADJ3 / INV7）
- **本地 + 受限进程 RCE / 临时 DoS / 低敏感信息泄露** → 低危档（本仓不报）

> 「远程」不要求攻击者做任何事——纯 0-click / 1-click（点一个链接/收一条消息）也算远程。  
> 「本地」允许攻击者自己安装一个普通 App，但不能要求用户配合钓鱼/诱导点击（INV3）。
