# 术语（官方口径）

| 术语 | 定义 | 挖掘时的含义 |
|------|------|--------------|
| **远程** | 不安装应用、不实际接触设备即可利用：网页浏览、短信/彩信、收发邮件、文件下载、无线网络通信等 | 最高优先；无需本地恶意 App |
| **本地** | 利用需要在受害系统安装应用，或需物理接触设备 | 允许「安装一个普通三方 HAP」的攻击者模型 |
| **TCB** | Trusted Computing Base：保护装置总体，含内核及驱动或等同内核的用户服务（如 init、vold） | 进 TCB = 严重档核心门槛 |
| **特权进程** | SELinux `system_app` 域中运行的应用/进程；system 级权限进程；root 进程 | 需要先拿到特权 → 大概率特权依赖/权限等价（无效向） |
| **普通应用进程** | 第三方应用进程，或内置但无 system 级权限的应用进程 | 攻击者应有的身份下限 |
| **受限进程** | 比普通应用进程受更严格权限约束的进程 | 本地受限进程 RCE 仅低危档 |

## 远程 vs 本地（易混点）

| 场景 | 归类 | 说明 |
|------|------|------|
| 网页 / 短信 / 邮件 / 文件下载触发 | **远程** | 官方原文列举 |
| Wi-Fi / 蓝牙 / WLAN / 同网报文 | **远程** | 属「无线网络通信」；**局域网 ≠ 本地** |
| **近场**（邻近射频 / 未配对也可收的报文） | **远程** | 与同网同类，**不是**本地；打到软总线/BT/Wi‑Fi 实现层按 N1/N6 |
| 分布式组网 / SoftBus / 跨设备未装 App 可达 | **远程** | 按远程条款（H5/H7/H2/C6 等） |
| 攻击者自装一个普通三方 HAP 后调用 | **本地** | 允许的本地模型 |
| 须物理接触按键 / 插线 / 拆机 | **本地**（且常 ADJ3） | 物理接触 → 降级或无效 |
| 须先 root / system / TOKEN_NATIVE 再打 | 非有效攻击者模型 | ADJ3 / INV7，不按远程抬档 |

> 「远程」不要求 0 前置操作——纯 0-click / 1-click（点链接 / 收消息 / 同网收包）都算远程。  
> 「本地」允许攻击者自己安装一个普通 App，但不能要求用户配合钓鱼/诱导点击（INV3）。

## 常见判定速记

- **远程（含同网/近场/分布式）+ 未鉴权 + 进 TCB / 特权数据** → 严重向
- **本地 + 仅需普通三方 HAP + 越权/隔离突破/数据读取** → 高危/中危向
- **任何「必须先 native / SA / root / system UID / 写系统路径」** → 特权依赖，直接判无效（ADJ3 / INV7）
- **任何「必须先再打一个未证明的洞」** → 链不完整（ADJ4 / INV2），按已证明单洞影响定或不报
- **本地 + 受限进程 RCE / 临时 DoS / 低敏感信息泄露** → 低危档（`none`，可报官方低危）
- **官方表述「受限场景 / 特定场景」下的 ACE** → 先按受限进程（L1/M1）；只有证明普通三方/默认可达远程内容可稳定触发才升档
- **远程绕过安装管控但仍需用户一次确认** → 不是 C4/H10
