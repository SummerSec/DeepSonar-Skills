# Phone OS 通用漏洞类型定义

OpenHarmony 本质是 **移动/嵌入式操作系统**。本文件定义 **Phone OS 通用** 漏洞类型（Android / iOS / OH 同类问题形态），用于：

- 审计时「该挖什么类问题」  
- 现象归类后映射到 `severity-levels.md` 四档条款  
- 与 `vuln-definitions` 八类（injection/rce/…）交叉：本文件偏 **系统层形态**，八类偏 **技术机理**

**纪律**：只写类型与判定规则；**不写**具体 CVE、公告条目、历史样板 ID。  
定级以 `severity-levels.md` + `adjustment-and-invalid.md` 为准；本文件不单独抬级。

**跨平台对照（概念，非实现）**：

| Phone OS 概念 | Android 侧近似 | iOS 侧近似 | OpenHarmony 侧近似 |
|---------------|----------------|------------|---------------------|
| 应用沙箱 | App UID + SELinux | App sandbox | HAP 沙箱 + MAC |
| 系统 IPC | Binder / System Server | XPC / Mach | SA / IPC / SAMGR |
| 进程孵化 | zygote / app_process | launchd | appspawn / nwebspawn |
| 权限模型 | permission / AppOps | TCC / entitlements | AccessToken / 权限 |
| 媒体解析 | mediaserver / codec | CoreMedia / ImageIO | multimedia / av_codec |
| 浏览器引擎 | WebView / Chromium | WebKit | webview / nweb |
| 近场/无线 | BT / Wi‑Fi / NFC | 同左 | communication_* / SoftBus |
| 可信基 | kernel + 关键驱动 | XNU + IOKit | kernel + init / HDF 等 TCB |
| 应用运行时 | ART / JIT | JSCore / dyld | Ark / ets_runtime / ACE |
| 元能力/导出 | Activity / Intent | URL scheme / extension | Ability / Want |
| 统一数据面 | ContentProvider / Clip | pasteboard / share | UDMF / 分布式剪贴板 |

---

## 0. 怎么用

1. 先定 **攻击路径**：远程（含同网/无线/文件/消息）或本地（普通三方 App）  
2. 在本文件命中 **类型**（可多选，取危害最高且证据充分的）  
3. 用类型表中的 **条款倾向** 打开 `severity-levels.md` 精匹配  
4. 过 Gate（`gates.md`）与 ADJ/INV  
5. 回填 `vuln_type`（八类之一，见 §13）

## 1. 内核与 TCB

| ID | 类型 | 定义（是什么） | 不是什么 | 路径 | 条款倾向 |
|----|------|----------------|----------|------|----------|
| K1 | **内核内存破坏** | 普通模型可达的 UAF / 越界写 / 竞态 / 双重释放，导致内核代码执行或任意读写 | 仅 oops/panic 且无利用路径 | 本地为主；少数远程协议栈 | H1；绕过内核缓解 → C2；远程进 TCB → C1 |
| K2 | **内核信息泄露** | 稳定读内核指针/敏感内存，常为后续利用一环 | 固定 4 字节无意义噪声、无稳定读口 | 本地 | 单洞多为 L3/M；**单独**难报 C/H |
| K3 | **驱动 / HDF / HAL 漏洞** | 用户态可达的驱动、HDF、板级/SoC 接口上的内存破坏或权限错误 | 须已 root 才能打开的调试节点；纯厂商闭源且无法 e2e | 本地；USB 邻接有时算本地物理 | 进 TCB → H1/C2；仅 crash → L2 |
| K4 | **缓解绕过** | 单独或配合使 KASLR/CFI/SELinux/seccomp 等失效 | 「理论上可绕」无 PoC | 本地 | M4；直接导致 ACE/关键泄露可抬 |
| K5 | **默认节点/设备权限过宽** | 出厂默认把内核/驱动节点、设备文件或 ioctl 对普通应用开放，使本不该达的 TCB 面可触达 | 开发者模式/已解锁 BL 才暴露的节点（ADJ6/ADJ7） | 本地 | 按最终实害；普通 App 可达且能 ACE/任意读写 → H1/C2；仅噪声读 → L3 |

**Phone OS 共性**：Android Binder/驱动、iOS IOKit、OH liteos / linux / **HDF** 驱动同属 TCB 面。K5 看的是 **默认 DAC/策略**，不是「节点存在即有洞」。

## 2. IPC、系统服务与混淆代理

| ID | 类型 | 定义 | 不是什么 | 路径 | 条款倾向 |
|----|------|------|----------|------|----------|
| I1 | **系统服务缺调用方鉴权** | 未校验 caller UID/token/权限即提供敏感能力或数据 | 规格本就对全员开放的只读状态 | 本地；少数暴露到网络则远程 | 数据 → M5/H5；能力开关 → M6/H8 |
| I2 | **IPC 中继 / 混淆代理（confused deputy / SA 中继）** | 低权方诱使高权服务以服务身份访问资源或调用其他 SA（含 client stub / callback stub 未鉴权转发） | 只能中继一步、最终无实害；须再叠未证明洞才能打到目标能力 | 本地 | 按**最终实害**定级；半链 → ADJ4/INV2 |
| I3 | **IPC 实现内存破坏** | Parcel/序列化/stub 分发中的 UAF、OOB、竞态 | 仅本进程可控堆损坏且无跨权 | 本地（服务常高权） | 进特权/TCB → M2/H1；普通/预置服务进程 → M2/M3；仅服务 crash → L2/INV8 |
| I4 | **跨进程句柄/对象误授** | 错误导出 binder/fd/token，导致权限扩散 | 同 UID 内部传递 | 本地 | H3 / M5 |
| I5 | **服务端反序列化鉴权绕过** | 对象/Parcel 反序列化路径上未校验 caller，把不可信对象当成已鉴权请求处理 | 仅反序列化崩溃、无身份或能力变化 | 本地 | 按绕过后的能力/数据；半链中继 → ADJ4/INV2 |

**OH 落点**：SA / SAMGR / stub / callback stub；**Android**：Binder/System Server；**iOS**：XPC/MIG。  
「可进一步提权打其他 SA」若第二步未证明 → **不要**按系统控制权报。

## 3. 沙箱、隔离与多用户

| ID | 类型 | 定义 | 不是什么 | 路径 | 条款倾向 |
|----|------|------|----------|------|----------|
| S1 | **应用沙箱逃逸** | 突破「应用数据与其他应用隔离」：读他 App 私有数据、写他 App 目录、逃到系统目录 | 仅访问自己的导出目录/共享集合 | 本地 | **H3** |
| S2 | **用户/工作资料隔离绕过** | 跨 user / profile / 访客 边界 | 同用户下多 App | 本地 | **H4** |
| S3 | **路径穿越（孵化/安装/解压/备份）** | `../` 或链接跟随写出沙箱 | 仅影响应用私有临时目录且无跨权 | 本地 | H3；直达 TCB 执行再抬 |
| S4 | **MAC/SELinux 策略缺陷** | 策略过宽使本不该通的域可访问 | 策略正确但 DAC 看起来宽、MAC 已挡 | 本地 | ADJ1：MAC 挡死不报；可绕 → 按影响 |

## 4. 权限、隐私与令牌

| ID | 类型 | 定义 | 不是什么 | 路径 | 条款倾向 |
|----|------|------|----------|------|----------|
| P1 | **运行时权限绕过** | 无授权使用相机/麦/位置/通讯录等敏感能力 | 权限组内「部分信息」降档场景 | 本地；远程/同网触发服务则远程 | M5/M6；远程 → H5/H8 |
| P2 | **权限状态/画像泄露** | 无敏感权限却可查询他 App 是否已授权等 | 仅查自己 | 本地 | M5；ADJ9 可降低危 |
| P3 | **Token/身份伪造** | 伪造 AccessToken、签名身份、caller 身份 | 仅调试构建 | 本地/远程 | 视可达数据/能力 → H3/H5/C5 |
| P4 | **权限等价误报** | 攻击者已有同权能力再调接口 | — | — | **INV7**，不报 |
| P5 | **权限实现/校验错误** | 权限管理器、后台任务、窗口、电话、网络管理等 **实现层** 把不该给的能力给了普通调用方（含「入参检测不完善」导致越权） | 规格本就开放的只读状态；仅导致本应用 crash | 本地；同网可达的服务接口算远程 | 数据 → M5/H5；能力开关 → M6/H8；仅 crash → L2/INV8 |

## 5. 组件导出、意图与深度链接

| ID | 类型 | 定义 | 不是什么 | 路径 | 条款倾向 |
|----|------|------|----------|------|----------|
| E1 | **导出组件未鉴权** | 任意 App 调起导出 Activity/Service/Provider/Receiver（或 OH Ability/Extension）完成敏感操作 | 明确设计为公开且无敏感后果 | 本地 | M5/M6；导致隔离破 → H3 |
| E2 | **Deeplink / URL Scheme / App Link / App Domain Verify 劫持或越权** | 恶意链接打开敏感页、带 token 参数、错误校验来源；或域名校验组件自身可被打到 ACE/鉴权失效 | 需用户确认的无害跳转 | 远程（点链）/本地 | 未鉴权读数据 → H5；本地数据 → M5；社工主导 → INV3；组件内 ACE 按进程档 |
| E3 | **Intent / Want / 参数注入** | 可控 extra/Want 参数导致 SQL/路径/命令/逻辑越权 | 仅影响恶意方自己 | 本地/远程 | 按最终 sink 归八类 + 本表影响 |
| E4 | **Ability / 元能力运行时越权** | Ability 拉起、跨 Ability 传参、Extension 回调未校验调用方，完成敏感操作或数据读取 | 同应用内导航；用户可见且须确认的跳转 | 本地 | M5/M6；隔离破 → H3 |

**Android Intent / iOS URL scheme / OH Want·Ability** 同型。

## 6. 内容提供者、存储与文件

| ID | 类型 | 定义 | 不是什么 | 路径 | 条款倾向 |
|----|------|------|----------|------|----------|
| F1 | **任意文件读/写** | 系统服务或导出接口可读写下本不该访问的路径 | 仅应用自身沙箱 | 本地；下载器/文档/存储服务常见 | H3 或 M5 |
| F2 | **共享存储/媒体库越权** | 绕过分区存储、媒体权限读相册/下载 | 用户已授予的范围 | 本地 | M5；跨用户 → H4 |
| F3 | **符号链接/TOCTOU** | 安装、拷贝、备份、OTA 窗口期换链 | 无竞争窗口的纯静态问题 | 本地 | 按最终文件影响；难稳可 ADJ4 |
| F4 | **下载/文档/存储服务路径问题** | download manager、document UI、storage service 等把服务身份可读的文件暴露给普通 App | 需已控服务身份 | 本地 | M5/H3 |
| F5 | **统一数据面 / 剪贴板 / 拖放越权** | UDMF、系统剪贴板、跨应用拖放在无对应权限时读出他 App 或系统敏感载荷 | 前台粘贴；用户明确分享的条目 | 本地 | M5；跨应用私有数据 → H3 |

## 7. 广播、通知与公共事件

| ID | 类型 | 定义 | 不是什么 | 路径 | 条款倾向 |
|----|------|------|----------|------|----------|
| B1 | **敏感广播/公共事件缺保护** | 手机号、短信、精确位置等进未保护事件 | 非敏感 UI 刷新事件 | 本地 | **M5** |

## 8. 媒体、图像与消息入口（经典远程面）

| ID | 类型 | 定义 | 不是什么 | 路径 | 条款倾向 |
|----|------|------|----------|------|----------|
| M1a | **媒体编解码内存破坏** | 畸形音视频/图片在系统解析器中 ACE 或进高权进程 | 仅第三方播放器、默认不解析 | **远程**（彩信/文件/网页/分享） | 普通 App/媒体进程 → H2；TCB → C1 |
| M2a | **系统自动解析入口** | 消息、缩略图、同步、剪贴板预览等 **零/少点击** 触发解析 | 用户显式用第三方打开 | 远程 | 同上，优先高 |
| M3a | **仅崩溃** | 解析导致 mediaserver 重启 | 可稳定 RCE | 远程/本地 | H7（远程设备影响）或 L2 |

**共性**：Android media framework、iOS ImageIO/CoreMedia、OH av_codec 同属高价值远程入口。

## 9. Web、JS 引擎与混合应用

| ID | 类型 | 定义 | 不是什么 | 路径 | 条款倾向 |
|----|------|------|----------|------|----------|
| W1 | **浏览器引擎远程代码执行** | 恶意网页在 WebView/引擎进程内 ACE | 仅渲染差异/UI bug；纯上游引擎、OH 默认路径不可达（INV4） | **远程** | **H2**；进 TCB 极少见 → C1 |
| W2 | **WebView 配置型** | `file://`、不安全 origin、js 桥未鉴权、通用 HTTPS 关闭校验 | 应用显式 `skip` 且非默认 | 远程/本地 | 默认坏 → H5/H2；App 自关校验 → ADJ5 |
| W3 | **JS Bridge 越权** | H5 调到本应原生鉴权的系统能力 | 仅应用业务 API 且已登录态等价 | 远程/本地 | M5/H5/H8 |
| W4 | **应用运行时内存破坏** | Ark / ets_runtime / ACE / 前端编译管线在处理不可信字节码、ABC、UI 树或输入时 UAF / OOB / 栈溢出 | 仅 IDE/编译期、开发者侧 crash；无法从普通 App 或远程内容触达 | 远程内容或本地 | 远程任意应用进程 → **H2**；本地普通 App → M3；本地预置/特权进程 → M2 |
| W5 | **运行时类型混淆** | 运行时把不可信值当成另一类型处理，导致越界或错误方法分发，最终 ACE | 仅类型报错/JS 异常，无内存破坏或越权 | 远程内容或本地 | 同 W4，按进程档与路径 |
| W6 | **受限场景 ACE** | 官方口径「受限场景 / 特定场景」下的运行时或服务 ACE：沙箱更严、默认不可达、或须非默认开关 | 已证明普通三方 App / 默认可达远程内容可稳定触发 | 视场景 | **L1**（本地受限）或 **M1**（远程受限）；**不得**按 H2/M3 报。证据不足时按受限处理 |

## 10. 无线、近场、蜂窝与分布式

| ID | 类型 | 定义 | 不是什么 | 路径 | 条款倾向 |
|----|------|------|----------|------|----------|
| N1 | **蓝牙/Wi‑Fi/NFC 栈内存或逻辑漏洞** | 无线报文导致 RCE/DoS/信息泄露 | 须配对后且双方恶意的无害互怼 | **远程**（同网/邻近/**近场**） | RCE → H2/C1；DoS → H7；读数据 → H5 |
| N2 | **配对/加密降级与 MITM** | 强制弱配对、缺完整性、默文明文（含跨设备 PIN 明文、组网降级） | 用户主动关安全开关 | 远程 | H5；ADJ5 看是否默认 |
| N3 | **蜂窝/RCS/短信/电话入口** | 运营商消息或电话栈触发解析器/入参漏洞 | 纯诈骗短信（社工） | 远程或本地（导出电话 SA） | 按解析后果；社工 → INV3 |
| N4 | **跨设备/分布式未授权** | 授权前或弱设备路径控制富设备；组网/软总线未鉴权转发 | 已双向强授权的同步 | 远程 | **C6 / H11**；读数据 → H5；写对端 → 按数据/代码影响 |
| N5 | **基带/厂商闭源组件** | 同左技术类 | 无法在目标 OH 版本 e2e | — | 能证才报；否则 needs_human / 不报 |
| N6 | **软总线 / 近场协议实现漏洞** | 邻近或同网报文打到软总线/分布式发现/传输实现：UAF、OOB、整数溢出、缺长度校验 | 须已完成强认证且双方恶意的无害互怼；纯上游协议通用洞且 OH 默认不可达（INV4） | **远程**（近场/同网） | ACE → H2/C1；设备重启/挂起 → H7；仅本进程崩溃看是否远程可达设备 |

## 11. 安装、更新、锁屏与可信执行

| ID | 类型 | 定义 | 不是什么 | 路径 | 条款倾向 |
|----|------|------|----------|------|----------|
| U1 | **静默安装/未授权安装** | 绕过用户确认安装或更新 | 企业 MDM 已授权场景 | 本地/远程 | **H10**；远程绕安装交互 → C4 |
| U2 | **签名/同源/降级/管控绕过** | 签名校验绕过、任务劫持式更新、可降级到漏洞版；远程绕过安装管控但仍需用户一次确认 | 用户明确装未知来源且流程符合规格 | 本地/远程 | 无交互静默 → H10/C4；**仍需用户确认** → 通常不按 C4/H10，按实际数据/完整性影响或 ADJ4 |
| U3 | **锁屏绕过** | 未解锁访问用户数据或桌面 | 合成生物识别（官方常排除） | 本地物理 | **H9**；ADJ 视是否物理 |
| U4 | **Keystore/TEE/密钥误用** | 密钥可被低权导出、认证可绑绕过 | 仅软件层「算法不优雅」无密钥 | 本地 | M7 或抬至数据影响档 |
| U5 | **安全启动/解锁 bootloader** | 持久化系统篡改 | 须解锁 BL | — | 多数 **ADJ6**，不作为主路径 |
| U6 | **OTA / 升级安装器缺陷** | 升级服务、sys_installer 等缺鉴权、TOCTOU、UAF，或把升级身份暴露给普通调用方 | 仅安装器自杀且无落盘/无提权；须已控 system 才能调 | 本地 | SA 中继半链 → ADJ4/INV2；普通 App 可达且 ACE → 按进程档（预置/特权 → M2）；改系统分区/静默装 → H10/H3 |

## 12. UI 表面、无障碍与侧信道

| ID | 类型 | 定义 | 不是什么 | 路径 | 条款倾向 |
|----|------|------|----------|------|----------|
| X1 | **叠加层/点击劫持** | 遮罩骗点授权 | 纯丑 UI | 本地 | 常偏 INV3/中低；能无感授权敏感能力再评 M6 |
| X2 | **无障碍/输入法滥用** | 读屏、键日志到敏感数据；输入法 callback stub 未鉴权中继 | 用户已授予且告知的能力 | 本地 | 权限等价 → INV7；未授权获取 → M5；中继半链 → ADJ4/INV2 |
| X3 | **剪贴板跨应用读** | 后台读剪贴板敏感内容 | 前台粘贴 | 本地 | M5/H3；与 F5 重叠时取危害高者 |
| X4 | **侧信道** | 传感器/时序推隐私 | 实验室理论、无稳定实害 | 本地 | 多 L3/ADJ4 |
| X5 | **窗口/叠加敏感信息** | 窗口管理等系统服务未鉴权，读出他应用界面、焦点或敏感窗口属性 | 仅本应用窗口装饰；用户已授权的录屏 | 本地 | M5；跨应用界面内容 → H3 |

## 13. 与八类 `vuln_type` 的映射

| Phone OS 类型（例） | 优先 `vuln_type` |
|--------------------|------------------|
| K1–K3、K5、M1a、W1、W4–W5、N1、N6 的 ACE | `rce` |
| I1–I2、I4、P1–P3、P5、E1–E4、U1–U3、N4 | `authz` |
| F1–F5、S1、S3 | `file-access` |
| W2 默认 TLS/证书、N2 | `ssrf` 少见；数据机密性多归 `authz`/`secrets` 视场景 |
| I5 / 系统服务反序列化鉴权绕过 | `deserialization`（实害是越权则主类型仍可 `authz`） |
| 可控进 shell/命令 | `injection` 或 `rce` |
| XXE 配置解析 | `xxe` |
| 密钥/token 硬编码或可导出、U4 | `secrets` |
| W6 受限场景 ACE | 按机理仍填 `rce`，`severity` 走 L1/M1，正式报告不报 |

现象跨类时：按 **最终可演示影响** 选一类主类型，rationale 可注明次要类。

## 14. 挖掘优先级（Phone OS 通用）

```
P0 远程默认可达：媒体/消息解析、WebView/引擎、无线/近场/软总线、自动预览
P1 本地普通 App：导出组件/Ability、SA/IPC 鉴权与中继、权限实现错误、沙箱路径、存储/UDMF、广播敏感数据
P2 本地进 TCB：内核/HDF/驱动（须证明普通 App 默认可达，含默认节点过宽）
P3 系统安装/OTA/包管理：静默装、升级安装器、域名校验组件（须普通模型可达）
P4 链式中段：纯信息泄露、单点缓解绕过、类型混淆无 ACE（常作组合，单洞慎报）
P5 通常降/无效：解锁 BL、开发者模式、system UID 前提、三方库无默认路径、半链中继、官方「受限/特定场景」ACE
```
