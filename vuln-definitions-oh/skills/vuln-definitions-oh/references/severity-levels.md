# OpenHarmony 四档危害定义

本文件是 OH 官方四档的 **可引用条款**（官方口径 2026-05）。  
定级时从上到下匹配：命中最高且证据充分的一级；证据不足则降级。  
每档给出 CVSS **区间（近似）**（精确分用 `vuln-scoring`，默认 v3.1、可按需 v4.0；不替代本文件定性）。

> 本仓报告模型：官方「严重→critical、高危→high、中危→medium、低危→none」。  
> 官方低危仍可领奖（≤1 万元），但 **不写入正式 finding**。  
> 官方安全公告常用 **CVSS 3.1**；仓内默认对齐 v3.1，需要时可另出 v4.0。

| 档 | 本仓映射 | 官方奖金上限（近似） | CVSS Base 区间（近似） |
|----|----------|----------------------|------------------|
| 严重 | `critical` | 最高 1,000,000 元 | ≥ 9.0 |
| 高危 | `high` | 最高 500,000 元 | 7.0 – 8.9 |
| 中危 | `medium` | 最高 200,000 元 | 4.0 – 6.9 |
| 低危 | `none` | 最高 10,000 元 | 0.1 – 3.9 |

---

## 1. 严重（Critical）

| # | 判定条件 |
|---|----------|
| C1 | 在 TCB 中 **远程执行任意代码** |
| C2 | 通过本地在 **特权进程或 TCB** 中执行任意代码，且 **能绕过内核消减措施** |
| C3 | 远程发起 **永久性 DoS**：设备无法再使用，或需重刷整个系统才可恢复 |
| C4 | 远程绕过应用安装及部分用户交互要求 |
| C5 | 未鉴权情况下远程访问受保护数据，达到 **特权进程访问任意数据** 的效果 |
| C6 | 分布式设备场景下，设备 **授权前** 跨设备远程代码执行 |

### 不是严重的情况

- 需先已是 native/SA/root 才可达（→ 特权依赖，判无效）
- 仅本地临时 DoS / 单应用闪退（→ 高/中危或无效）
- 远程但只能触发受限进程 RCE（→ 中危 M1）

---

## 2. 高危（High）

| # | 判定条件 |
|---|----------|
| H1 | 本地在 TCB 中执行任意代码 |
| H2 | 在 **普通应用进程** 中远程执行任意代码 |
| H3 | 绕过将应用数据与其他应用隔离开来的安全机制 |
| H4 | 绕过将用户或个人资料彼此隔离开来的安全机制 |
| H5 | 未鉴权情况下 **远程** 访问受保护数据（普通应用可访问的数据） |
| H6 | 本地永久性 DoS：设备需重刷操作系统或恢复出厂才可使用 |
| H7 | 远程暂时性 DoS：导致远程挂起或重新启动设备 |
| H8 | 无需用户交互 **远程** 开启/关闭通常需用户发起的功能 |
| H9 | 绕过屏幕锁（合成生物识别数据的绕锁不在范围） |
| H10 | 本地绕过用户交互实现 **静默安装** |
| H11 | 分布式：控制 **弱设备** 实现对 **富设备** 的远程代码执行 |

### 定级提示

- **默认安全控件失效**：默认路径下 TLS/WSS 等校验失效，远程/同网可未鉴权读改受保护业务数据 → 优先对照 H5/H7
- **非默认路径不算**：须 App 主动 `skip`、显式关校验才触发 → 按 ADJ5 / INV 处理，不报高危

---

## 3. 中危（Medium）

| # | 判定条件 |
|---|----------|
| M1 | 在 **受限进程** 中远程执行任意代码 |
| M2 | 通过本地在特权进程、预置应用中执行任意代码 |
| M3 | 通过本地在普通应用进程中执行任意代码 |
| M4 | 绕过特权进程/TCB 中的缓解技术（若直接导致任意代码执行或关键信息泄露，可酌情提升） |
| M5 | 未鉴权情况下 **本地** 访问受保护数据（需请求权限才可访问，或仅限特权进程访问的数据） |
| M6 | 无需用户交互 **本地** 开启/关闭通常需用户发起的功能 |
| M7 | 不安全的加密算法及密钥存储，可导致敏感信息泄露 |

### 定级提示

- **本地未鉴权读受保护数据**：普通三方 App 在无对应敏感权限时，仍可读他 App 需授权才可见的状态/数据 → 对照 M5；若仅为权限范围内的部分信息，按 ADJ9 降档

---

## 4. 低危（Low → 本仓 none）

| # | 判定条件 |
|---|----------|
| L1 | 通过本地在受限进程中执行任意代码 |
| L2 | 本地暂时性 DoS：系统挂起或设备重启 |
| L3 | 低敏感信息泄露（官方原文：`低风险的信息泄露`） |

### 本仓处理

- 必须会定级为 low（语义完整），但 `reportable: false`
- 官方口径下 ≤1 万元档；除非命中更高档升级，否则不占主线

---

## 5. 前提 × 影响 速查矩阵（系统向）

| 影响 ↓ \ 路径 → | 远程（未装 App） | 本地普通三方 HAP | 本地需 native/SA |
|------------------|------------------|------------------|------------------|
| 进 TCB / 特权数据 | **严重** | 严重（能绕缓解）／高危 | 权限等价 → 无效 |
| 普通应用数据 / 隔离突破 | 高危 | **高危～中危** | 权限等价 → 无效 |
| 受限进程 / 临时 DoS / 低敏感信息 | 中危 | 低危 | 低危或无效 |
| 单应用自杀 / 自触发 / skip 开关 | 无效 | 无效 | 无效 |

> 矩阵按官方条款归纳；具体以条款 # 为准。判断「权限等价」：利用所需权限本身就能造成同等效果 → 无效（INV7）。  
> 「远程」列含 **同网 / 局域网 / 分布式组网报文**（见 `terminology.md`），不是「本地」。

---

## 6. 影响语 → 条款映射（抽象）

将常见「路径 + 结果」说法对齐到本文件条款。用于定级辅助，**不是**历史漏洞清单。

| 影响语（抽象） | 倾向条款 | 备注 |
|----------------|----------|------|
| 远程/同网 → 内核或 TCB 任意代码 | C1 | 须默认路径可达 |
| 本地普通攻击者 → TCB 任意代码 / 稳定 root | H1；能绕内核缓解 → C2 | 须先 system UID → ADJ3 |
| 远程/同网 → 普通应用进程任意代码 | H2 | 运行时/Web 等 |
| 本地 → 穿越沙箱 / 跨应用数据隔离 | H3 | 路径穿越类 |
| 远程/同网 → 未鉴权访问受保护数据或敏感服务 | H5 | 含相机等 SA 未鉴权访问 |
| 远程/同网 → 设备挂起/重启（临时） | H7 | 非永久砖机 |
| 远程 → 无交互开关敏感能力 | H8 | |
| 本地 → 静默安装 | H10 | |
| 分布式授权前跨设备 RCE | C6 | |
| 弱设备控富设备远程代码 | H11 | |
| 远程 → 受限进程任意代码 | M1 | |
| 本地 → 预置应用 / 特权进程内代码执行 | M2 | 非 TCB 或未绕缓解 |
| 本地 → 普通三方应用内代码执行 | M3 | |
| 本地 → 未鉴权读受保护数据（含无权限收敏感广播） | M5 | 低敏感 → ADJ9/L3 |
| 本地 → 无交互开关需用户发起的功能 | M6 | |
| 本地 → 仅当前应用 crash / 临时 DoS | L2 / INV8 | 本仓不报 |
| 本地 → 内核/栈少量非敏感字节泄露 | L3 | 本仓不报 |
| 利用需 system UID / 另一漏洞 / 仅中继半链 | ADJ3 / ADJ4 / INV2 | 不进正式报告 |

**纪律**：**不得**为贴近某厂商公告数量或历史 case 而把 medium 抬进正式报告。  
类型是否「常见」以 `phone-os-vuln-types.md`（Phone OS 共性）为准，不以单一 OS 已披露清单为上限。
