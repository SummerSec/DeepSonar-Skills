# 挖掘门禁 Gate A–D 与报告要求

发现可疑点后 **按顺序回答**；任一「否」→ 不进入深度 PoC，最多记对内缺陷。

## Gate A · 攻击者是谁？

- [ ] **A1** 攻击者可以是：**未安装 App 的远程方**，或 **仅安装普通三方 HAP 的本地方**？
- [ ] **A2** 不需要：TOKEN_NATIVE / system_app / 预置 SA / root / 写 `/data/service` 类系统路径？
- [ ] **A3** 不需要：开发者模式、解锁 bootloader、刷自签系统、打开 `nosharefs` 等非默认开关？

## Gate B · 默认与可达？

- [ ] **B1** 受害方或系统在 **出厂默认 / 文档默认 API 用法** 下会走到漏洞路径？（不是 `skip=true`）
- [ ] **B2** 普通 Phone 标准系统（或社区明确纳入的 small/standard）可复现，而非仅 mini/lite？
- [ ] **B3** SELinux / seccomp / 权限模型在 **真实策略** 下仍可达？（不要只看 `chmod 0666`）

## Gate C · 有没有「直接实害」？

至少命中一条，且能演示：

| 实害类型 | 合格例子 | 不合格例子 |
|----------|----------|------------|
| 机密性 | MITM 读到业务 token/PII；越权读他 App 受保护数据或明确敏感状态 | “可能泄露某结构体布局”且无稳定读口 |
| 完整性 | MITM 篡改消息；伪造身份；静默改策略且对用户生效 | 仅 CBC 无 MAC 的理论 bit-flip，写不了落盘 |
| 可用性 | 远程导致设备重启/挂起；永久不可用 | 仅杀自己的进程、单 App 闪退 |
| 授权绕过 | 未授权访问需权限才有的数据/能力；静默装包；绕锁屏 | 已有同权权限再调接口 |
| 隔离绕过 | 跨应用读数据、跨用户边界 | 仅同 UID 自打 |

- [ ] **C1** 危害 **大于** 攻击者已合法持有的能力（**非权限等价**）
- [ ] **C2** 不依赖钓鱼文案 / 诱导狂点（允许 1 次正常安装恶意 App 的本地模型）
- [ ] **C3** 能用一句话说清：**谁、在什么默认条件下、对谁、造成什么可观测结果**

## Gate D · 利用链是否闭合？

- [ ] **D1** 从初始条件到危害 **中间步骤均由攻击者控制或默认成立**
- [ ] **D2** 不是“再叠加一个未证明的 RCE / 再写落盘”才成立
- [ ] **D3** 准备得出：**完整可编译 PoC + 默认配置复现步骤 + 截图/日志**

## 决策

```
Gate A/B/C/D 全过 → 进入 L3 复现与投递队列
任一不过       → 写入「对内/无效」口径，不占主线
争议项         → 先做最小 e2e，再决定是否投递
```

## 报告要求（官方硬性）

1. **人工验证**；AI 辅助生成报告将降低优先级
2. **影响与根因**：受影响组件版本、现象说明、具体代码逻辑（反编译/反汇编/开源代码辅证）
3. **分步复现**：以 **恢复出厂后的环境** 为起点；关键步骤标注 + 结果截图
4. **完整可编译 PoC**：源码、依赖库、编译配置、编译/运行环境说明；结果与说明一致；有结构体则附加结构说明与恶意字段说明
5. PoC 不侵犯第三方知识产权；不含宗教或法律禁止内容

**禁止**：未经授权访问/下载/修改/删除他人数据、钓鱼与社会工程、上报前公开 PoC 细节。

## 实害话术模板（报告里必须写清）

```text
【攻击者】普通三方应用 / 同网 MITM / 远程未认证报文 …
【前提】默认配置；无需 XXX 权限；无需开发者模式 …
【步骤】1 … 2 … 3 …
【可观测危害】
  - 机密性：读到 …
  - 完整性：改成 …
  - 授权：在未获 … 权限下完成了 …
【边界】不能 …（主动写清，避免审方按过高档驳回）
【对照条款】severity-levels.md#H5（远程未鉴权访问受保护数据）…
```

### 合格 vs 不合格表述

| 不合格 | 合格 |
|--------|------|
| “TLS 校验逻辑不完善” | “默认 WSS 接受自签，MITM 可回显会话 token（附 101 日志）” |
| “ATM 接口鉴权弱” | “无 GET_SENSITIVE 的普通 App 用 tokenId 读出他 App CAMERA=GRANTED” |
| “IsSACall 实现不严” | （若仅 native 可调）→ **不投递**；对内记鉴权模型缺陷 |
| “AES-CBC 无完整性” | （若不能写落盘）→ **不投递**；有写+静默接受 bit-flip 再报 |
