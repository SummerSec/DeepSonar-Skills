# 官方公告机理类型定义

本文件定义 OpenHarmony 安全公告「漏洞描述」使用的 **机理类型**。  
用语来自 2021–2026 自研披露的抽象归并（**不写** CVE / SA 编号 / 具体条目）。  
与 `phone-os-vuln-types.md`（攻击面形态）互补：先定 **机理**，再定 **落点**，再按 `severity-levels.md` 定档。

公告一行是 `{组件} {机理}` + `{路径}攻击者可造成{后果}`。三件事必须拆开，不能用组件名当类型。  
三方库 / 上游 linux 树条目不建本表类型（INV4）。

定级以四档 + ADJ/INV 为准；本文件不单独抬级。`severity_rule` 只引用 `severity-levels.md#…`。

---

## 0. 怎么用

1. 用 §9 对照表把公告用语落到 **一个 ID**  
2. 打开该 ID 小节：定义 / 成立 / 不是 / 定级  
3. 路径：远程 / 近场 / 本地（近场=远程，见 `terminology.md`）  
4. 进程档：TCB / 特权·预置 / 普通应用 / 受限·特定场景  
5. 后果：ACE / 永久或临时 DoS / 敏感或低敏感泄露 / 越权读写 / 静默装包  
6. 填 `mechanism`、`phone_os_class`、`vuln_type`

**成立通例**：默认可达 + 能演示实害 + 危害大于已有权限。  
IV / RACE / DOS 标签本身不是完整漏洞，必须落到可演示后果。

## 2. 内存破坏

### MW 越界写

**定义**：可控数据或长度使写越过对象/缓冲区/内核对象边界。含公告「访问非法地址」「内存溢出」「越界读写」的写侧。

**成立**：可控写越界，并能演示 ACE、任意写或稳定设备级 DoS。  
**不是**：仅越界读；无利用路径的不可控堆损坏；非默认可达。

| 后果 | 条款倾向 |
|------|----------|
| 远程进 TCB ACE | C1 |
| 本地 TCB ACE 且绕过内核缓解 | C2 |
| 本地 TCB ACE | H1 |
| 远程普通应用进程 ACE | H2 |
| 远程受限 / 特定场景 ACE | M1 |
| 本地特权/预置进程 ACE | M2 |
| 本地普通应用进程 ACE | M3 |
| 本地受限进程 ACE | L1 |
| 远程设备挂起/重启 | H7 |
| 本地永久砖机 | H6；远程永久砖 → C3 |
| 仅本地临时 DoS / 单应用 crash | L2 / INV8 |

**`vuln_type`**：ACE → `rce`。形态：K1/K3、I3、M1a、W1/W4、N6。

### MR 越界读

**定义**：读越过合法边界，稳定带出非本对象内容。含「内核任意内存越界读」「数组越界访问」读侧。

**成立**：有稳定读口，能重复读出非噪声数据。  
**不是**：固定少量无意义噪声；仅崩溃无外带。

| 后果 | 条款倾向 |
|------|----------|
| 远程未鉴权读受保护/特权数据 | H5 / C5 |
| 本地未鉴权读受保护数据 | M5 |
| 低敏感 / 内核少量非敏感字节 / 泄漏内核栈无进一步利用 | L3 |
| 读口仅服务后续 ACE | 单洞 L3/M，不按 ACE 报 |
| 越界读导致远程设备 DoS | H7；本地临时 → L2 |

**`vuln_type`**：凭据 → `secrets`；越权数据 → `authz`。形态：K2、I3、M1a、W4、N6、F5/X3。

### UAF 释放后使用

**定义**：对象释放后仍被使用。公告「UAF」「指针释放后使用」同义。

**成立**：能证明 UAF 且后果可演示。  
**不是**：无稳定触发；释放后只走空指针且仅本应用 crash（改 NPD/INV8）。  
**定级**：同 MW。`vuln_type`：`rce`。形态：K1、I3、U6、W4、N6、多媒体/蓝牙/相机/会话。

### NPD 空指针解引用

**定义**：空指针被解引用。公告亦写「空指针引用」。

**不是**：未证控制流劫持就把 NPD 写成 ACE。  
**定级**：仅 crash → 本地 L2/INV8，远程/近场影响设备 → H7；已证 ACE → 按 MW。

### IO 整数溢出

**定义**：整数溢出/回绕导致错误长度、索引或分配。公告早期亦写「整形溢出」。

**成立**：溢出接到 MW/MR/UAF/越权/DoS。  
**不是**：溢出后被检查挡死。  
**定级**：按落地后果，不按「有溢出」本身。

### SO 栈溢出 / HO 堆溢出

**定义**：栈帧或堆块写出边界。软总线/组网报文上的堆溢出按 **远程/近场**。

**定级**：同 MW。近场堆溢出 ACE → H2/C1；近场仅 DoS → H7。

### TC 类型混淆

**定义**：把不可信值当成另一类型，导致错误分发、越界或越权。公告亦写「数据类型混淆」。

**成立**：导致 ACE 或越权，不是仅类型报错。  
**不是**：官方「受限/特定场景」未证普通模型 → W6，走 L1/M1，不上抬 H2/M3。  
**定级**：ACE 同 MW；仅越权走 AUTHZ。形态：W5、ArkUI。

### DF 双重释放

**定义**：同一分配释放两次。公告亦写「重复释放」「内存二次释放」。  
**定级**：接到 ACE/任意写按 MW；仅不稳定 crash 按 NPD/L2。

## 3. 并发与校验

### RACE 条件竞争

**定义**：检查与使用、释放与使用、授权与投递之间存在可赢窗口。

**成立**：窗口可稳定赢并接到 UAF / 换链 / 越权 / ACE。  
**不是**：难复现（ADJ4）；无最终实害。  
**定级**：按接到的实害。形态：F3、U6、I3、内核。

### IV 不当输入验证

**定义**：长度、类型、范围、协议字段或安装包有效性未充分校验。公告常用 **根因标签**。  
同义：入参检测不完善、输入校验、数据校验不完善、未判断数据长度、系统调用用户态参数使用错误、安装 hap 未做有效性判断。

**成立**：必须落到 MW/MR/UAF/NPD/AUTHZ/LEAK/PATH/FILE/DoS 之一。  
**不是**：只写「缺校验」无后果；规格本就开放（ADJ10）。  
**定级**：禁止用 IV 本身选档。

## 4. 授权、中继与文件

### AUTHZ 权限绕过

**定义**：未校验 caller UID/token/权限，或默认节点/策略过宽。  
同义：权限穿越、权限校验绕过、缺少权限校验、不正确的权限管控、权限管理不当、默认权限配置错误、模块权限控制错误、权限管控被绕过。

**成立**：无对应权限仍完成敏感操作或读出受保护数据。  
**不是**：权限等价（INV7）；须 system/native（ADJ3）；SA 中继半链无实害（改 BYPASS + INV2）。

| 后果 | 条款倾向 |
|------|----------|
| 远程未鉴权读特权任意数据 | C5 |
| 远程未鉴权读普通受保护数据 | H5 |
| 本地未鉴权读受保护数据 | M5 |
| 远程/本地无交互开关需用户发起的功能 | H8 / M6 |
| 跨应用隔离破 / 任意读写文件 | H3 |
| 跨用户/profile | H4 |
| 静默安装 | H10；远程绕安装交互 → C4；仍需用户确认 ≠ C4/H10 |
| 仅部分信息（如是否已授权） | ADJ9 → 常 L3 |

**`vuln_type`**：`authz`。默认节点过宽进 TCB → 形态 K5。

### BYPASS 校验绕过 / SA 中继

**定义**：低权方诱使高权服务以服务身份访问资源或调用其他 SA。含反序列化路径把不可信对象当已鉴权请求、client/callback stub 未鉴权转发。

**成立**：中继之后有 **最终实害**（数据/能力/ACE）。  
**不是**：只走到 stub、第二步未证明（ADJ4/INV2）。  
**定级**：按最终实害；半链不报。`vuln_type`：`authz` 或 `deserialization`。形态：I2/I5。

### PATH 路径穿越

**定义**：孵化、安装、解压、备份等路径拼接可 `../` 或跟随链接，写出/读出预期目录。

**成立**：普通模型可达，且跨出应用私有临时目录。  
**不是**：仅影响自己的导出目录。  
**定级**：跨应用/系统目录 → H3；直达 TCB 执行再抬。`vuln_type`：`file-access`。形态：S3。

### FILE 任意文件读/写

**定义**：系统服务或导出接口（如下载器、存储服务）以服务身份读写下本不该给普通 App 的路径。

**成立**：能读/写他 App 或系统受保护文件。  
**不是**：仅应用自身沙箱；须已控服务身份。  
**定级**：H3 或 M5。`vuln_type`：`file-access`。形态：F1/F4。

## 5. 泄露、密码学与映射

### LEAK 敏感信息泄露

**定义**：受保护数据、密钥、token、他 App 私有内容、公共事件中的个人数据、或内核栈地址，在未鉴权时被读出或落盘不当。

**成立**：内容需权限或仅特权可访问，且能稳定读出。  
**不是**：低风险信息（L3）；权限范围内部分信息（ADJ9）。  
**定级**：远程 → H5/C5；本地受保护 → M5；内核栈少量非敏感 → L3；密钥导出 → M7 或抬至数据档。  
**`vuln_type`**：密钥/token → `secrets`；否则 `authz`。

### ML 内存泄露

**定义**：分配不释放。公告亦写「资源未释放」「堆内存泄露」。

**不是**：把 ML 写成敏感泄露——除非内容本身是密钥/指针且能读出（改 LEAK/MR）。  
**定级**：本地临时 → L2；远程设备挂起 → H7。

### CRYPTO 明文 / 缺认证加密

**定义**：默认路径下 PIN/密钥明文过网、组网报文无需认证和加密、或缺完整性校验，使同网/近场可 MITM。

**成立**：出厂默认即弱，能读改受保护业务数据或降低 MITM 门槛。  
**不是**：用户主动关安全开关（ADJ5）。  
**定级**：默认可读改受保护数据 → H5；仅算法不优雅无密钥 → 不够。`vuln_type`：`authz` 或 `secrets`。形态：N2。

### UNINIT 未初始化资源

**定义**：缓冲、对象或证书模块资源未初始化即被读出或使用。

**成立**：能稳定读出残留敏感内容，或未初始化导致 ACE。  
**定级**：敏感缓冲 → M5/H5/L3（视敏感度）；ACE 按 MW。`vuln_type`：`secrets` 或 `authz`。

### MMAP 内核内存非法映射

**定义**：驱动/设备节点把内核或物理内存不当地映射给普通用户态。

**成立**：普通 App 默认可打开该节点并获得映射。  
**定级**：任意读写内核 → H1/C2；读机密/改敏感文件 → 按数据档（常 H3/M5）。形态：K3/K5。`vuln_type`：`rce` 或 `file-access`。

## 6. DOS 标签

公告有时把「DOS 攻击漏洞」「进程崩溃」「异常报文导致设备重启」写成类型。这是 **后果**，不是机理。

1. 先找回根因（NPD / IV / MW / HO / RACE…）  
2. 再按后果定档：远程/近场设备重启 → H7；本地永久不可恢复 → H6；远程永久 → C3；仅本应用 crash → INV8/L2  

禁止用「有 DoS」单独抬到 C/H。

## 7. 公告影响语 → 条款

| 影响语（抽象） | 条款倾向 |
|----------------|----------|
| 远程 / 近场 → 任意应用中执行代码 | H2 |
| 远程 / 近场 → TCB 执行代码 | C1 |
| 本地 → TCB 执行代码 / 获取 root | H1；绕内核缓解 → C2 |
| 本地 → 预装/特权进程执行代码 | M2 |
| 本地 → 普通应用进程执行代码 | M3 |
| 受限场景或特定场景执行代码 | L1 / M1，不上抬 H2/M3 |
| 远程 / 近场 → 设备挂起/重启 | H7 |
| 本地 → 设备无法启动 / DoS 无法恢复 | H6 |
| 本地 → 仅应用/服务 crash | L2 / INV8 |
| 远程未鉴权 → 信息/敏感信息泄露 | H5；特权任意数据 → C5 |
| 本地 → 泄露、绕过鉴权访问数据 | M5；低敏感 → L3 |
| 本地 → 任意读写文件 / 穿越沙箱 | H3 或 M5 |
| 结合其他漏洞可进一步 root | 单洞按已证影响；不自动抬严重 |
| 远程绕过管控安装，仍需用户交互 | 不按 C4/H10 |
| 取得高权限后再 ACE | ADJ3，无效 |

## 8. 与八类、形态的交叉

| 机理 | 优先 `vuln_type` | 常见形态 |
|------|------------------|----------|
| MW / UAF / SO / HO / DF / MMAP（ACE） | `rce` | K1/K3/K5、I3、M1a、W1/W4/W5、N1/N6、U6 |
| AUTHZ / BYPASS | `authz`（反序列化根因可 `deserialization`） | I1/I2/I5、P、E、S、B、U |
| PATH / FILE | `file-access` | S3、F1/F4 |
| LEAK / UNINIT / CRYPTO（密钥） | `secrets` 或 `authz` | U4、P2、B1、N2、K2 |
| IV / RACE / IO / DOS | 跟落地后果 | 随 sink |
