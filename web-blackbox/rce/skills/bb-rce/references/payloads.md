# RCE 最小验证提示

> 仅用于已授权验证。不要构建完整攻击框架。

## 探测方向

- 模板预览/邮件模板/报表引擎
- 表达式/规则引擎/沙箱逃逸迹象
- 文件上传+解析执行链
- 调试端点、Actuator、heapdump 间接链

## 合格证据

- 可执行任意命令或等价代码
- 可写 webshell / 反弹 shell 路径明确
- 云环境可拿实例权限

## 不合格（不报）

- 仅报错含类名无执行面
- SSTI 只数学运算无 RCE 链且无敏感读

## 记录要求

- 完整 URL、方法、关键参数  
- 响应差异或 OOB 记录  
- 影响说明必须达到 Critical/High
