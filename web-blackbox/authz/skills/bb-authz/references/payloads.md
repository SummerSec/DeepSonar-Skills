# AuthZ 最小验证提示

> 仅用于已授权验证。不要构建完整攻击框架。

## 探测方向

- 水平越权: 替换 resource id/uuid
- 垂直越权: 普通用户调 admin API
- 认证绕过: 改 header、路径、方法
- 批量枚举敏感对象

## 合格证据

- 未认证访问管理功能
- 普通用户提升到管理员
- 可批量读取/修改他人敏感数据或资金操作
- 可接管任意账户

## 不合格（不报）

- 仅看到自己非敏感字段差异
- 无敏感数据的信息性 IDOR
- 需已是管理员才能复现的配置问题

## 记录要求

- 完整 URL、方法、关键参数  
- 响应差异或 OOB 记录  
- 影响说明必须达到 Critical/High
